# Live2D model packages

`manifest.json` (+ `manifest.json.sig`) lists the downloadable Live2D models the
app installs from the [`models` release](https://github.com/xShiroeNguyenx/desktop-companion/releases/tag/models).
How to pack, sign and publish one: [RELEASE.md](../RELEASE.md), "Releasing a Live2D model".

The models in these packages are original artwork licensed under
[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/): free to share and
remix with credit, not for commercial use. See [ASSETS-LICENSE.md](../ASSETS-LICENSE.md).
