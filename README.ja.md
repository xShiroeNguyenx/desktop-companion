# Desktop Companion

🌸 Windows 向けのスタンドアロン Live2D デスクトップペット。**AI翻訳**・**クイック返信**・
**タスク保存**を内蔵し、あらゆるアプリ（Teams、ブラウザ、Word…）で動作します。

🌐 **[ウェブサイト / 紹介ページ →](https://desktop.techdecoded.net/)**

**言語:** [English](README.md) · [Tiếng Việt](README.vi.md) · **日本語**

## 機能

- **Live2D デスクトップペット** — 透明・最前面・ドラッグ可能なコンパニオン。Windows
  起動時に自動起動。右クリックで**円形メニュー**。
- **翻訳** — **任意の**アプリでテキストを選択 → カーソル付近に 🌸 が表示 → **クリック**で
  即翻訳、**長押し**で**円形メニュー**が展開:
  🌐 翻訳 · 📋 コピー · 💬 返信 · 💭 ペットに質問 · 📝 タスク保存 · 🗂️ フルパネル。
  表示中に **Ctrl+C** を押して選択テキストをコピーすることもできます。
- **ペットとチャット** — 右クリック → 💬 **クイックチャット**。返答は吹き出しに一語ずつ
  表示され、内容に合わせてペットの表情が変わります。現在時刻と未完了のタスクを把握し、
  直近 10 往復を記憶します（この PC にのみ保存、🗑 で削除）。⏹ で途中停止できます。
- **選択テキストについて質問** — 🌸 の円形メニューで 💭 を選ぶと、選択したテキストを
  添付した状態でチャットが開きます。
- **会話でタスク管理** — 「明日 17 時までにレポートを送るってリマインドして」と頼むと
  締め切り付きでタスクに追加、「レポート終わった」と伝えると完了にします。実際に保存
  できたときだけ吹き出しで確認し、どのタスクか確信がないときは推測せずに聞き返します。
- **コンパニオンに名前を** — ペット上の小さなカードで名前をお願いされ、付けた名前で
  お礼を言い、呼び方（ベトナム語の人称の組み合わせ、または日本語・英語では名前＋
  さん／くん／ちゃん／様）を尋ねます。**ベトナム語・日本語・英語**で話し、チャットできます。
  設定 →「Bạn đồng hành」でいつでも変更可能。
- **ペットから話しかける** — しばらく会話がないと（設定: オフ / 30 分 / 1 時間 / 2 時間）、
  一番古い未完了タスクのリマインドや休憩の声かけを一言話します。離席中・画面ロック中・
  全画面表示中は話さず、自発的な発言は 10 分以上の間隔をあけます。🔕 **おやすみモード**
  （円形メニューまたはトレイ）で 1 時間静かにできます。
- **締め切り** — 各タスクの 📅 で設定。タスク画面は締め切りの近い順に並び、緊急度で色分け。
  当日の朝・1 時間前・締め切り時刻・期限切れ後は 1 日 1 回（最大 3 日）お知らせします。
  ペット非表示中やプレゼン中は **Windows 通知**で届きます。
- **休憩リマインド**（初期状態でオン、API キー不要）— PC 作業 45 分で目の休憩、60 分で
  水分補給と立ち上がり。5 分離席すると休憩扱いになり、近いタイミングのリマインドは
  ひとことにまとめます。
- **完了をお祝い** — タスクを終えるたびにペットがお祝い。最後の 1 件、締め切り前の完了、
  その日 3・5・10 件目は特別なひとこと。
- **タスクをデスクトップにピン留め** — 📌 でタスクがピンク色の付箋に。押しピンには
  コンパニオンの顔。好きな場所へドラッグでき、✓ で完了、✕ でピンを外す、📍 で常に
  最前面。タスクやメモ内のリンクはクリックで開けます。
- **🍅 集中セッション** — 25 分集中して 5 分休憩（どちらも変更可）。ペットの上にカウント
  ダウンの輪が表示され、集中中は締め切り以外で話しかけません。
- **離席に気づく** — マウス・キーボード操作が 10 分ない（または画面ロック）とうとうと
  居眠りし、戻ると声をかけます。CPU／RAM 高負荷の警告も選べます（初期状態はオフ）。読む
  のはオン／オフの状態と割合だけで、ウィンドウ名・アプリ名・画面の内容は読みません。
- **💗 なかよし度** — 毎日の利用、タスク完了、集中セッション、チャット、なでなで、ゲームで
  5 段階のなかよし度が少しずつ上がります（1 日の上限あり、減ることはありません）。毎朝
  今日の締め切り数と一緒にあいさつし、記念日（7／30／100／365 日、毎年の記念日、連続日数、
  レベルアップ）とあなたの誕生日をお祝い。仲良くなるほど話し方も打ち解けます。
- **🎮 ミニゲーム** — 専用ページ（💞 → 🎮）に 3 つのゲーム。それぞれ別ウィンドウで開き、
  Miu が一手ごとに反応します：じゃんけん（3・5・7 勝先取）、数当て（1〜10 から 1〜100、
  ヒントあり）、ボム処理班（3 サイズのマインスイーパー）。「★ 今日」のゲーム、成績、
  今日ゲームでもらったなかよしポイントも同じページに表示されます。
- **🌦 天気** — 雨・雪・桜・落ち葉・霧・晴れ・星空を画面全体に表示。マウス操作を
  妨げず、全画面表示・ロック・離席中は自動で止まります。エフェクトを選ぶ、季節と時間に
  合わせる、または選んだ都市の**実際の天気**に合わせることができます。天気予報カード
  （現在・7 日間・降水確率つき 24 時間グラフ・°C / °F）と、デスクトップに固定できる天気
  ウィジェット付き。天気が変わるとペットがひとこと話し、朝には天気予報を伝えます。
  **Ctrl+Alt+W** でエフェクトをオン／オフ。位置情報は調べません — 選んだ都市の座標だけを
  [Open-Meteo](https://open-meteo.com) に送ります（API キー不要）。
- **📅 画面に置ける月カレンダー** — トレイ、リングの 💞 → 📅、または設定から小さな月
  カレンダーを固定できます。各日にベトナムの旧暦の日付を表示し、ベトナムの祝日（テト・
  中秋節・フン王の命日など）に印、休日は赤、期限のあるタスクの日には点（期限切れは赤）。
  日をクリックすると旧暦の詳細と期限のタスクを表示し、その日が期限のタスクも追加できます。
  あなたの誕生日には 🎂。📍 をオフにしない限り、ほかのウィンドウより手前に表示されます。
  祝日・旧暦の15日（満月）・1日にはペットがひとこと話し、前日の夜にもお知らせします。
- **🕐 世界時計つきの時計** — PC の時刻と旧暦の日付に加え、最大 2 つの都市（東京・ソウル・
  ニューヨーク・ロンドンなど）の時計を時差と「明日」「昨日」つきで表示。サマータイムも自動。
  🍅 の行から集中を開始でき、残り時間をカウントダウンします。
- **🍬 キャンディとコレクション** — タスク完了・集中セッション・チャット・なでなで・
  ゲーム勝利でキャンディがもらえます（なかよし度と同じ1日の上限）。🍬 コレクション
  （リングの 💞 → 🍬）でウィジェットスキン、ごほうびエフェクト（花火・紙吹雪）、
  桜吹雪、ハートの雨、しゃぼん玉、流れ星）、吹き出しのスタイル、文字選択のお花、
  キャラクターセット（🐰 バニー・🐱 ネコ・🦊 狐・❄️ 雪の国）、ミウの表情セット
  （❄️ 雪・🦇 ゴシック）と交換できます。雪の国・ネコ・狐は全パネルの見た目も変えます
  （氷・ゴシックロリータ・狐の社）。飾りだけで、お金では買えません。
- **🎰 キャンディカプセル** — コレクションのうさぎカプセルマシンをまわせます。1回 100 🍬、
  10回 1000 🍬、排出率はマシンに表示（ノーマル 65%・レア 25%・エピック 10%）。レアが
  出ないまま10回目はレア以上確定、エピックが出ないまま50回目はエピック確定、ダブりは
  キャンディで返ってきます。レアとエピックは専用の演出で開きます。ショップでの交換も
  いつでもできます。
- **🧩 ウィジェットをひとまとめに** — 設定 → *🧩 Widget* でカレンダー・時計・天気ウィジェットの
  固定／解除、追加の時計の選択、🧹 で固定中のウィジェットを右側に一列に整列できます。
- **クイック返信** — メッセージを選択し、返信内容をベトナム語で入力すると、AI が元の
  メッセージの言語（英語／日本語／…）で自然な返信を作成します。
- **選択なしでテキストアシスタント** — 右クリック → 🗂️ **Mở đầy đủ** でペットの横に空の
  入力欄付きで開きます。テキストを入力・貼り付けして翻訳、返信、タスク保存ができます。
- **タスク保存** — 選択したテキストを TODO 化。タスクウィンドウは「未完了」「完了」の
  2 カラム構成で、作成日時と完了日時を記録し、各タスクにメモを編集できます。
- **翻訳コンテキスト** — 設定にプリセットのコンテキスト（例:「フォーマルな業務チャット」）。
  クイック翻訳のトーンを合わせられます。デフォルトを選択、または未使用も可。
- **パネルに加わるペット** — 設定またはタスクを開くと、ペットが 2 カラムの間へ移動します
  （クリックスルーなので操作の邪魔になりません）。閉じるか最小化すると元の位置に戻ります。
- **🌸 Bunny Lounge**（任意、設定 →「Diện mạo」）— 設定・タスク・テキストアシスタント・
  天気カード・ミニゲームページの縁に女の子たちが寄りかかります。パネルに重なる部分は薄くなるので読みやすさはそのまま。
- **カーソル追従** — カーソルがペットの近くにあるとき、頭・目が追従します。
- **拡大／縮小** — `Ctrl` + マウスホイールでサイズ変更。サイズは保存されます。
- **カスタム Live2D モデル** — 任意のフォルダから `*.model3.json` を読み込み。
- **サウンド** — 操作効果音（つつく／なでる 等）を日本語／ベトナム語／英語で。
- **AI プロバイダー** — Anthropic Claude または Google Gemini（自分の API キーを使用）。
  モデル一覧は各プロバイダーから取得可能。
- **カスタムホットキー** — キャプチャ用ショートカットを変更可能（既定 `Ctrl+Shift+Space`）。

## インストール

[Releases](../../releases) ページから最新のインストーラーをダウンロード:

- **`Desktop Companion_x.y.z_x64-setup.exe`**（NSIS）または **`…_x64_en-US.msi`**（MSI）

実行するとアプリが自動起動し、システムトレイに常駐します。

> 現在は Windows のみ対応。WebView2 ランタイムが必要（Windows 10/11 にはプリインストール）。

## はじめに

1. **API キーを設定** — トレイアイコン → **設定 (Cài đặt)** → プロバイダー（Anthropic
   または Gemini）を選択 → キーを貼り付け → **保存**。
2. **翻訳** — どこでもテキストを選択 → 🌸 をクリック。
3. **返信** — メッセージを選択 → 🌸 を長押し → 💬 **返信**を選択 → ベトナム語で入力 → **生成**。
4. **タスク** — トレイ → **Tasks**、または 🌸 の円形メニューで 📝 **タスク保存**を選択。
5. **チャット** — ペットを右クリック → 💬 **クイックチャット** → 入力 → `Enter`。

### トレイメニュー

ペット表示/非表示 · タスク · 設定 · クリックスルー切替 · 🍅 集中の開始／停止 · 🔕 おやすみモード（1 時間）· 🌦 天気エフェクトのオン／オフ · ☁️ 天気予報 · 📅 月カレンダーの固定／解除 · 終了

### ペットを右クリック

カーソルを中心に円形メニューが展開します。アイコンにカーソルを合わせると中央の
ピルに名称が表示され、カテゴリをクリックすると輪がその項目に切り替わり、ピルは
戻るボタンになります。

外観（モデル変更、カーソル追従、モーション、つつく）· サウンド（音声言語、環境音、
ミュート）· クイックチャット · タスク · 設定（いちばん下）·
💞 Đồng hành（🍅 集中、💗 なかよし度、🎮 ミニゲーム、📅 月カレンダー、🔕 おやすみモード）·
☁️ 天気（予報、エフェクトのオン／オフ、デスクトップに固定）· 🗂️ Mở đầy đủ（テキストアシスタント）

**モデル**と**モーション**はキャラクターの左右 2 カラムで開くため、選択中もキャラクターが
見えたままです。選択を重ねても開いたまま — × または `Esc` で閉じます。

## ソースからビルド

### 前提条件

- [Rust](https://rustup.rs)（stable）+ MSVC C++ ビルドツール
- [Node.js](https://nodejs.org) 18+
- Tauri の前提条件 — <https://v2.tauri.app/start/prerequisites/> を参照

### コマンド

```bash
npm install
npm run dev      # 開発モードで実行
npm run build    # src-tauri/target/release/bundle/ にインストーラーを生成
npm test         # JS ユニットテスト（app/js/*.test.js）
cd src-tauri && cargo test   # Rust ユニットテスト
```
